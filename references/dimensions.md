# 关联方核查 20 维度字段映射

本文档说明本技能从注协行业库分批取得的 20 个关联方核查维度，以及核查引擎使用的核心字段。联网流程不再一次请求全部 61 个行业库维度。

审计人员在阅读核查报告时，可以参考本文档理解证据来源。

## 数据取得边界

- 搜索、详情、股东、主要人员、股权和子公司发现有独立查询接口。
- 客户、供应商、最终受益人和变更记录没有独立查询接口，只能从维度导出批次取得。
- 主动发现入口只保证被审计单位本身取得以下 20 个维度；扩展出的候选不会逐家导出客户、供应商等文件。
- 候选不等于关联方，红旗不等于硬关联；字段缺失或未命中也不等于不存在关系。

## 字段处理说明

### 数据清洗

- **电话归一化**：拆分多值（逗号/分号分隔），去区号，统一手机格式（11位）
- **邮箱归一化**：提取域名，排除公共邮箱（qq.com、163.com 等）
- **地址归一化**：去 HTML 标签、空格、标点、邮编、省市后缀，保留核心地址
- **姓名归一化**：去 HTML 标签、空格

### 特殊处理

- **法人变更.xlsx**：含 HTML 标签，使用 `strip_html()` 清理
- **持股比例字段**：equity API 中为 `czbl`，非 `investRatio`
- **公共邮箱域名**：排除 qq.com、163.com、126.com、sina.com、sohu.com、hotmail.com、gmail.com、outlook.com、foxmail.com 等
