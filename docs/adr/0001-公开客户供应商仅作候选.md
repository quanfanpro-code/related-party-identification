# 决策 0001：公开客户和供应商仅作为候选

## 状态

已接受

## 背景

注协客户表和供应商表中的“关联方名称”字段，实际表示一条公开交易关系的另一方名称。它描述“这家公司与谁发生客户或供应商关系”，并不表示该交易对手已经被认定为会计准则意义上的关联方。旧逻辑按字段字面含义直接生成“硬关联”，造成全部公开客户和供应商被误判。

## 决策

客户表、供应商表中的交易对手只用于扩充主动发现候选范围，并分别记录“公开客户关系”或“公开供应商关系”。该信息本身不进入风险命中、不生成风险等级，也不用于推断“未披露关联方”。只有候选在股权控制、关键人员、联系方式或地址、历史工商联系、担保资金往来、资源匹配等独立规则中命中有效证据时，才进入关联方核查报告。

## 影响

这样会显著减少误报，同时保留客户和供应商作为后续穿透核查入口的价值。以后即使注协导出字段名称不变，代码、测试和文档也必须按照这里定义的业务语义处理，不能恢复按字段名称直接认定关联方的旧逻辑。
