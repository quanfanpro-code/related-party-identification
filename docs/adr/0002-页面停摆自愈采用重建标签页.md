# 页面停摆自愈采用重建取数标签页

下载途中取数页面进入后台冻结态（页面停摆）时，自动重建取数标签页并重试该次请求，而不是要求用户全程保持 Edge 前台不动。

背景：2026-10-25 实测确认，标签页 hidden 后页面内定时器与 fetch 回调被挂起，取数调用永不完成；重建标签页立即恢复。用户面对两三小时的长任务，明确选择"支持正常用电脑、技能在后台跑"（方案 A），否决"约定跑任务时别动 Edge"。

考虑过的替代：约定用户不切窗口（约束几乎必然被打破，历史故障即证据）；客户端拉长退避重试（冻结页面不会自愈，只会拉长空转）。自愈失败时（Edge 最小化、扩展断连、登录失效）不硬撑，暂停并保留已保存进度、给出操作指引。
