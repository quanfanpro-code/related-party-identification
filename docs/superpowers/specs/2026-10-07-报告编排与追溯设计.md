# 报告编排与追溯设计

## 方案比较与决定

保留十四张表只补导航，改动较小但同一公司对仍需跨七表阅读；七张表统一证据，能同时按公司对和证据类别筛选；额外建设 HTML 前端会增加另一套输出。本次采用用户已要求接手完成的七表方案，继续使用 Excel 原生筛选及超链接，无宏、无新依赖。

## 数据流

被审计单位导出 → 发现候选并持久保存来源 → 候选名单整批导出 → 按两个原始目录共同读取 → 原始记录位置随字段保留 → 比对和稳定编号 → 同一批结果生成全部报表和统计。

候选导出采用独立状态文件和原始子目录，沿用现有导出器。恢复时比较企业范围，不把被审计单位导出误用作候选导出；失败时保存候选来源并暂停。名单入口保留用户名单来源；离线入口只读实际目录，不联网。

## 追溯与统计

读取原始 Excel 时保留真实行号（含空行）、工作表名、列号和原文。每条命中关联实际使用的记录，不把同一维度的全部数据冒充该条命中的证据。明细一条命中可占多行来源，证据编号相同；证据条数按编号去重，公司对按无序公司对去重。短摘要和完整来源分别展示。

公司来源、取得资料、比对和命中是不同概念。报告纳入所有目标和候选，包括缺少基础工商资料者。七类检查覆盖与源维度取得状态分别解释；规则失败进入缺口页。第三方之间的命中只描述第三方之间关系。日期同时注明生成时间和核查基准日，原始数据日期按资料记录展示，不将文件修改时间称为取得时间。

## 工作表与交互

七张表以深海蓝统一标题、表头和导航。顶部为标题/返回目录，第三行为明细表头，第四行起数据；冻结前三行和关键识别列。超链接落到证据块和汇总行；内部编号另建名称以便引用。原始文件链接使用相对路径并包含工作表和单元格位置，文本也保留位置，便于不同 Excel 客户端人工定位。长证据不截断，换行和限制列宽；数据单元格不合并。风险等级文字独立于颜色。

## 错误处理、验证与回滚

文件缺失、空表、单家公司无记录及导出明确无数据分别记录。残缺基础数据不引发未说明的默认无风险；原始文件冲突不覆盖。独立目录保持各批原始证据。新文件名延续防覆盖规则；新任务字段有默认值兼容旧状态。

先用自动测试复现候选未比对、缺少源定位、报告结构和统计缺口，再修复。用模拟数据覆盖七类命中、负例、缺失、失败恢复及链接回读；最后运行技能分发校验。备份已逐文件校验，可按备份还原被修改文件，新文件由用户决定保留或回收，不自动删除。
